# Data Governance Foundations - Course Materials

This repository holds the datasets and practice activities for the **Data Governance Foundations** course. It's built for learners working through the course, no prior GitHub experience is needed to complete an activity; each module's instructions tell you exactly what to open and what to do.

All datasets in this repository are **synthetic** invented for teaching purposes. They do not contain real customer or personal data.

Each module gets its own folder, added as its exercises go live. Start with Module 1:

- [Module 1 practice](module-01/practice-instructions.md)
- [Module 1 dataset](module-01/customer-data.csv)

Answer keys for assessed activities are kept outside this public repository.
